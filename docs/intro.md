# 🏠 Makani Home Lab Engineering Playbook

## Building an Enterprise Smart Home from First Principles

Welcome to the engineering record of Makani's Home Lab.

This project combines two parallel deliverables:

1. A working, production-inspired Smart Home platform.
2. A living engineering playbook documenting the architecture, decisions, implementation, verification, troubleshooting, and lessons learned.

This is not simply a collection of installation commands.

The playbook explains:

- What each technology is
- Why it was selected
- How it fits into the architecture
- How it was implemented
- How success was verified
- What problems were encountered
- What could be improved
